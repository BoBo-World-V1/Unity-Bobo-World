Original Features Only For Your Game
These are the ones that can make your game feel like its own thing.
World Heart system
Each world has a core that grows stronger based on building, activity, farming, and exploration.

World traits
Every world can roll special traits like rich ore, low gravity, stormy, fast crop growth, crystal bloom, haunted.

Living block evolution
Certain blocks transform over time based on neighbors, biome, or weather.

World specialization
A world can develop into a mining world, farm world, trade world, adventure world, or craft world.

Community bonuses
If multiple players build or work together in the same world, the world gains temporary buffs.

Memory / story blocks
Blocks that can store text, messages, lore, ownership history, or tiny interactions.

World reputation
Well-maintained or popular worlds gain unlocks, buffs, or prestige.

Seasonal world events
Meteor shower, corruption growth, bloom season, treasure rain, cave collapse, crystal storm.

Tool mastery
Tools get better depending on how the player uses them, not just because they crafted a stronger version.

World goals
Each world can have optional goals like build a village, harvest 500 crops, mine rare crystal, host 10 visitors.
